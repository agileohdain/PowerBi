Notes et guides d'apprentissage Power BI.

## Ressources officielles

- [Documentation Power BI](https://learn.microsoft.com/power-bi/)
- [Microsoft Learn — parcours Power BI](https://learn.microsoft.com/training/powerplatform/power-bi)
- [Communauté Power BI (Community)](https://community.powerbi.com/)

## Plan d'apprentissage suggéré

1. **Bases** : importer des données Excel, créer un tableau croisé dynamique visuel
2. **Modélisation** : relations entre tables, mesures DAX simples
3. **Visuels** : graphiques, segments, info-bulles
4. **PBIP / Git** : versionner ses rapports avec ce dépôt
5. **Publication** : publier sur service Power BI, rafraîchissement
